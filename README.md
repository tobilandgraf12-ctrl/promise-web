# promise-web

Código y archivos propios de la tienda online de Promise (Tiendanube, plantilla Morelia).

- `promise.js`: secciones extra de la página de inicio (Por qué Promise, preguntas frecuentes, el local, cierre).
- Se carga desde Tiendanube → Diseño → Pie de página → "Código Javascript o HTML del sello":

```html
<script src="https://cdn.jsdelivr.net/gh/tobilandgraf12-ctrl/promise-web@VERSION/promise.js" defer></script>
```

Usar siempre una versión fija (tag o commit) para que los cambios se vean al instante y se puedan revertir.
